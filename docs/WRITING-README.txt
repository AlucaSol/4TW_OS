4TW-OS Offline Typewriter documents

Drafts and other writing saved here can be opened normally from Windows.
FocusWriter uses plain UTF-8 .txt files by default. Press Ctrl+S to save normal
edits. FocusWriter 1.9 has crash/session recovery, but not timed saving to the
open document.

Always use the 4TW-OS clean shutdown control and wait for complete power-off
before removing the USB. In Windows, safely eject the USB before unplugging it.
